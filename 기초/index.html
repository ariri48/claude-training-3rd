개념 · CLAUDE.md

CLAUDE.md = 나만의 업무 설명서

폴더에 이 파일을 두면 Claude가 매번 자동으로 읽고 내 맥락에 맞게 일합니다.

💼 마케팅팀 예시
# CLAUDE.md ## 나는 누구 - 마케팅팀 김사원. 주간보고를 매주 금요일 작성. ## 자주 하는 일 - Dooray 태스크를 모아 주간보고(.md)로 정리 - 보고 형식: 완료 / 진행중 / 다음주 계획 ## 규칙 - 존댓말, 불릿 3개 이내, 수치는 굵게 - 숫자: ##,### 천단위 콤마 표시 - 날짜: 반드시 date 명령어로 검증 (추측 금지) ## 보안 - 개인정보(주민번호, 계좌번호 등) 절대 입력 금지 - API 키, 비밀번호 → .env 파일에 분리 - 사내 기밀자료 입력 금지
📊 정산팀 예시
# CLAUDE.md ## 나는 누구 - 재무팀 박대리. 매월 파트너 수수료 정산 담당. ## 자주 하는 일 - 빌링 엑셀에서 파트너별 매출 합산 - 거래명세서 대조 후 차이 리포트 작성 ## 규칙 - 금액: ##,### 천단위 콤마, 0원이면 "-" - VAT 계산: 원 미만 절사 (// 10 * 10) - 날짜·요일: date 명령어로 반드시 확인 ## 보안 - 파트너 실명·이메일 대량 출력 금지 - DB 내용 통째로 출력 금지 → 요약만
📍 어디에 두나
작업하는 폴더 맨 위에 CLAUDE.md 파일로
🛠️ 만드는 법
/init 입력 또는 "CLAUDE.md 만들어줘"
🔁 계속 다듬기
어색한 결과가 나오면 규칙 한 줄씩 추가
⚠️ CLAUDE.md에 적어도 안 지킬 때가 있어요
왜 안 지킬까?
• 지시가 너무 많으면 우선순위가 흐려짐 — 뒤쪽 규칙을 놓침
• 대화가 길어지면 컨텍스트에서 밀림 — 초반엔 잘 지키다가 후반에 잊음
• "적절히", "가능하면" 같은 모호한 표현은 무시되기 쉬움
잘 지키게 하려면?
• 규칙을 짧고 단정적으로 ("~하지 않는다", "반드시 ~한다")
• 가장 중요한 규칙을 맨 위에 배치
• 안 지키면 "CLAUDE.md 다시 읽어" → 즉시 재로드
• 규칙이 많으면 카테고리별 ## 섹션으로 구분
🔒 진짜 무조건 지키게 하려면? — 3가지 강제 장치
① IMPORTANT 접두어
규칙 앞에 IMPORTANT: 또는 CRITICAL:을 붙이면 Claude가 더 높은 우선순위로 처리
IMPORTANT: 금액은 반드시 ##,### 형식 CRITICAL: 개인정보 절대 출력 금지
② Settings 차단 (파일 접근 금지)
settings.json에서 특정 파일 읽기/쓰기를 시스템 레벨로 차단
// .env 파일 접근 원천 차단 "deny": ["Edit .env*", "Read .env*"]
③ Hooks (코드로 강제)
도구 실행 전후에 자동 검사 스크립트 실행 — 위반 시 작업 자체를 차단
// 예: 파일 저장 전 개인정보 검출 "hooks": { "preToolUse": [검사 스크립트] }
요약: CLAUDE.md = "부탁" / Settings·Hooks = "강제". 보안처럼 절대 어기면 안 되는 건 Settings·Hooks로 잠그세요.
💡 잘 쓰는 팁
누구 · 자주 하는 일 · 규칙 · 보안 — 이 4가지만 적어도 충분합니다. 길게 쓰기보다 구체적으로, 단정적으로.
한 번 적어두면 "내가 누구고 뭘 원하는지"를 다시 설명할 필요가 없습니다.

가장 많이 받는 질문입니다. 결론부터 말씀드릴게요.

📋 Anthropic 공식 데이터 정책 (검증 완료)
항목내용
AI 모델 학습 학습 안 함 — API/Claude Code를 통해 전송된 데이터는 모델 학습에 사용되지 않습니다.
출처: Anthropic Commercial Terms "may not train models on Customer Content"
서버 전송 전송됨 — AI 연산은 내 PC가 아니라 Anthropic 클라우드 서버에서 처리됩니다. 터미널에서 실행되지만, 입력한 내용은 서버로 보내져요.
암호화 AES-256(저장 시) + TLS 1.2+(전송 시) 암호화 적용
출처: Anthropic DPA Schedule 2
데이터 삭제 계약 종료/해지 후 30일 이내 삭제. 서비스 이용 중에는 답변 생성·악용 방지를 위해 임시 저장됩니다.
출처: Anthropic DPA Section H.1.b
웹(Free/Pro) vs API 웹 버전은 설정에 따라 학습에 활용될 수 있음. API·Claude Code는 학습 안 함. 정책이 다릅니다!
🚫 그래도 절대 입력하면 안 되는 것
  • • 개인정보: 주민번호, 여권번호, 계좌번호, 카드번호
  • • 인증정보: 비밀번호, API 키, 토큰, SSH 키
  • • 영업비밀: 전략기획, 미공개 마케팅, R&D 기밀
  • • 민감정보: 휴대폰번호, 이메일 주소, 건강정보
✅ 이건 괜찮아요
  • • 업무 프로세스 자동화 요청 (엑셀 정리, 보고서 등)
  • • 공개된 정보 기반 작업 (서비스 목록, 매뉴얼 등)
  • • 가명·더미 데이터로 테스트 후 실데이터 적용
  • • 매출·이용자 수 등 집계 데이터 분석 (개인 식별 불가 시)
🧠 "그럼 서버 전송 자체를 안 하려면?"
Claude Code가 "이 엑셀 분석해줘"를 처리할 때, 파일 내용(매출 숫자, 이름 등)을 읽어서 서버로 보냅니다.
Claude가 컬럼 구조와 값을 직접 봐야 코드를 짤 수 있기 때문이에요. 연산만 가는 게 아니라 데이터 자체가 전송됩니다.

하지만 이미 만들어진 .py 파일을 python script.py로 실행하면? → 서버 전송 없이 내 PC에서만 동작!

"전송 = 기밀 유출인가요?"
아닙니다. 암호화(AES-256)되어 전송되고, 학습에 안 쓰이고, 계약 종료 후 삭제됩니다.
Google Docs나 Notion, Dooray도 서버에 데이터가 올라가는 건 마찬가지예요.

다만 NHN 보안정책은 "우리 서버 밖으로 나가는 것 자체"를 제한합니다.
유출 여부가 아니라 "통제권 이탈" 관점이에요. 그래서 개인정보·기밀은 넣지 마세요.
🔒 학습에 안 쓰이고, 암호화도 되지만, 우리 서버 밖으로 나가는 건 사실 — "애매하면 안 넣는다"가 원칙입니다.

Claude Code로 메일을 보내려면 먼저 IMAP(수신)과 SMTP(발신) 설정이 필요합니다.

서버imap.dooray.com

비밀번호Dooray 비밀번호
📤 SMTP (메일 발신)
서버smtp.dooray.com
포트465 (SSL/TLS)
계정Dooray 이메일 주소
비밀번호Dooray 비밀번호
🔐 .env 파일 만들기 — 초보자도 3분이면 끝!
비밀번호를 코드에 직접 적으면 위험해요. 별도 파일에 따로 보관하는 겁니다.
📝 만드는 법 (메모장으로 OK!)
  1. 1. 메모장을 열어요 (또는 아무 텍스트 편집기)
  2. 2. 아래 내용을 복사·붙여넣기하고, 내 정보로 수정
  3. 3. "다른 이름으로 저장" 클릭
  4. 4. 파일명을 .env 로 입력 (앞에 점 필수!)
  5. 5. 파일 형식을 "모든 파일 (*.*)"로 변경
  6. 6. 작업 폴더에 저장 (Claude Code 실행하는 그 폴더)
📋 이 내용을 복사하세요
# 내 메일 설정 (이 파일은 나만 봐야 해요!) EMAIL_ADDRESS=내아이디@nhn.com EMAIL_PASSWORD=내비밀번호 SMTP_SERVER=smtp.dooray.com SMTP_PORT=465 IMAP_SERVER=imap.dooray.com IMAP_PORT=993
Q. 파일명이 꼭 .env여야 해?
→ 네, 관례적으로 .env입니다. Claude가 자동으로 이 파일을 찾아요.
🛡️ .gitignore란? (비개발자용 설명)
Git(코드 관리 도구)에 파일을 올릴 때, "이 파일은 올리지 마"라고 적어두는 목록이에요.
.env에 비밀번호가 있으니까, 실수로 인터넷에 올라가지 않도록 .gitignore에 적어두는 거예요.
Claude에게 "이 폴더에 .gitignore 만들어서 .env 추가해줘"라고 하면 알아서 해줍니다.

# CLAUDE.md에 이렇게 적어두면 ## 메일 발송 - 메일 발송 시 .env 파일의 SMTP/IMAP 정보를 사용한다 - 발송 후 IMAP으로 보낸메일함에 저장한다 - 1건씩 개별 발송, 발송 간격 2초
→ 이제부터 "메일 보내줘"만 하면 알아서 .env 읽고, 보낸메일함까지 저장해요!
STEP 1 · 1건 테스트
> 나에게 테스트 메일 1건 보내줘
먼저 내 메일로 테스트해서 발송이 되는지 확인
(CLAUDE.md에 적어뒀으니 SMTP 언급 안 해도 OK)
STEP 2 · 대량 발송
> 메일_명단.xlsx를 읽어서 각 수신자에게 개인화된 안내 메일을 1건씩 개별 발송해줘
엑셀의 이름·이메일·금액으로 개인화 메일 자동 생성
STEP 3 · 보낸메일함 저장
> 보낸 메일을 IMAP으로 보낸메일함(Sent)에도 저장해줘
SMTP는 발송만 함 → IMAP append로 보낸메일함에 기록 남기기
💡 대량 메일 발송 팁
  • • 1건씩 개별 발송: To에 수신자 1명만 → 개인화 + 프라이버시 보호
  • • 발송 간격: 건 사이에 1~2초 간격 → 스팸 필터 방지
  • • 테스트 먼저: 전체 발송 전 반드시 내 메일로 1건 테스트
  • • CC/Reply-To: 발신 주체에 따라 규칙 설정 가능 (CLAUDE.md에 적어두면 자동)
⚙️ 보낸메일함 저장 원리
SMTP는 발송만 담당하고 "보낸메일함"에 자동 저장하지 않습니다.
IMAP으로 Sent 폴더에 append하면 Dooray 웹에서도 보낸 기록을 확인할 수 있어요.

활용 ④ · 보고서 & PPT

design.md로 사내 템플릿 맞춘 문서 만들기

Claude Code는 PPT(python-pptx)도 만들 수 있습니다. 핵심은 design.md에 사내 템플릿 규칙을 적어두는 것.

📌 design.md = 디자인 설명서
폰트·색상·레이아웃 규칙을 적어두면, Claude가 매번 같은 스타일로 PPT를 만듭니다.
# design.md 예시 ## PPT 규칙 - 폰트: NanumGothic (본문 11pt, 제목 20pt Bold) - 색상: 제목 #191919, 강조 #4f46e5 - 로고: assets/logo.png (우측 하단) - 한 슬라이드에 내용 5줄 이내
STEP 1 · 보고서 초안
> 매출 분석 결과로 팀장 보고용 PPT 만들어줘. design.md 규칙 따라서
STEP 2 · 수정 지시
> 3페이지에 월별 추이 차트 추가하고, 표지에 로고 넣어줘
📄 마크다운 보고서
"보고서.md로 저장" → 빠른 텍스트 보고
🌐 HTML 보고서
"HTML 보고서로" + design-system.md → 브랜드 통일
📊 PPT 생성
"python-pptx로 .pptx 만들어줘" → 파워포인트 파일
🎯 핵심: design.md에 우리 팀 규칙을 적어두면, 누가 만들어도 같은 스타일의 문서가 나옵니다.
