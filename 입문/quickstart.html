데스크톱 앱 vs CLI, 뭐가 다른가요?

5분
🔀
헷갈리기 쉬운 두 가지
같은 Claude인데 할 수 있는 일이 다릅니다
▼
구분💻 데스크톱 앱⌨️ CLI (Claude Code)
실행아이콘 더블클릭터미널에서 claude
내 파일❌ 업로드만✅ 직접 읽고 쓰기
파일 생성❌ 못 함✅ 엑셀·코드 직접 생성
명령어 실행❌ 못 함✅ Python·Git 자동 실행
MCP 연동⚠️ 일부만✅ Dooray 등 풀 연동
CLAUDE.md❌ 없음✅ 폴더마다 규칙 설정
Skill❌ 없음✅ 확장팩 설치 가능
요금무료/Pro/MaxPro/Max (유료 전용)

데스크톱 앱이 좋을 때

가벼운 질문, 글 다듬기, 이미지 첨부 대화

CLI가 압도적인 때

파일 처리, 자동화, 업무툴 연동, 반복 작업

데스크톱 앱 = 예쁜 채팅창 · CLI = 내 컴퓨터에서 직접 일하는 비서. 둘 다 깔아두면 좋습니다.

CLAUDE.md — 나만의 규칙 설명서

10분
📝
CLAUDE.md가 뭔가요?
"내 업무는 이렇습니다"를 적어두는 파일
핵심 ▼
CLAUDE.md는 Claude Code가 매번 자동으로 읽는 규칙 파일입니다.
한 번 적어두면, 매번 같은 말을 반복하지 않아도 됩니다.
# CLAUDE.md 예시 # 내 정보 - 이름: 홍길동 - 부서: 마케팅팀 - 담당: 파트너 관리 # 보고서 규칙 - 존댓말 사용 - 숫자는 천 단위 콤마 (1,000) - 날짜는 YYYY-MM-DD 형식
Claude Code 안에서 /init 입력
자동으로 CLAUDE.md 파일이 생성됨
내용을 내 업무에 맞게 수정 (Claude에게 시켜도 OK)
폴더마다 다른 CLAUDE.md를 둘 수 있어요. 정산 폴더에는 정산 규칙, 보고서 폴더에는 보고서 규칙.
🎨
design.md — 디자인 규칙
HTML/웹 결과물의 스타일을 일정하게
활용 ▼
design.md는 Claude가 HTML·웹페이지를 만들 때 참조하는 디자인 가이드입니다.
회사 로고 색상, 폰트, 레이아웃 규칙 등을 적어두면 매번 일관된 결과물이 나옵니다.
# design.md 예시 # 브랜드 - 메인 컬러: #191919 - 폰트: Noto Sans KR - 로고: assets/logo.png # 레이아웃 - 모바일 반응형 필수 - 최대 너비: 1200px
CLAUDE.md와 같은 폴더에 두면 됩니다. 디자인 관련 작업을 자주 시킨다면 만들어 두세요.

Dooray MCP 연동

15분
🔌
MCP가 뭔가요?
Claude에게 외부 도구(Dooray 등)를 연결하는 표준 규격
▼

MCP 없이

  • Dooray 내용을 내가 복사해서 붙여넣기
  • 결과를 다시 손으로 옮겨 입력

MCP 연결하면

  • Claude가 Dooray를 직접 조회
  • "조회 → 정리 → 저장"이 한 번에
MCP는 "USB-C 케이블" 같은 것. Claude에게 손과 눈을 달아주는 연결 규격입니다.
🛠️
Dooray MCP 연동하기
토큰 발급 → 설치 → 연결 확인
필수 ▼
Dooray API 토큰 발급
Dooray → 좌측 하단 프로필 → 설정 → API/개인 인증 토큰 → 새 토큰 발급
소스 다운로드 + 설치
cd $HOME\Documents git clone https://github.com/ariri48/dooray-mcp.git cd dooray-mcp python setup.py
토큰 입력 — setup.py가 물어보면 복사해 둔 토큰 붙여넣기. 테넌트 ID는 그냥 Enter.
연결 확인 — Claude Code를 껐다 다시 켜고:
> Dooray에서 내가 속한 프로젝트 하나만 알려줘
프로젝트 이름이 나오면 연동 성공!
⚠️ 토큰은 비밀번호입니다. 화면 공유·채팅에 노출 금지!

업무 활용 맛보기

15분
📋
Dooray 업무 자동화
태스크 조회, 정리, 글 작성을 말로 시키기
활용 ▼
# 이런 식으로 시켜보세요 > 내 프로젝트에서 이번 주 마감인 업무 알려줘 > 내 개인 프로젝트에 "MCP 테스트" 업무 글 하나 만들어줘 > 이번 주 업무 현황 표로 정리해줘
Claude가 Dooray에서 직접 데이터를 가져와 정리합니다. 복사·붙여넣기 없이 "말"로만.
📊
엑셀 데이터 정리
파일을 읽고 분석하고 저장까지
활용 ▼
# 엑셀 파일이 있는 폴더에서 > 매출_데이터.xlsx 열어서 팀별 합계 내고 표로 정리해줘 > 이 엑셀에서 중복된 행 찾아서 알려줘 > A열 기준으로 정렬하고 새 파일로 저장해줘
Claude Code는 파일을 직접 읽고 결과를 새 파일로 저장합니다. 채팅형 AI와 가장 다른 점이에요.
✉️
대량 메일 발송
명단 엑셀 → 개인화된 메일 자동 발송
활용 ▼
수신자 명단 엑셀 준비 (이름, 이메일, 개인화 정보)
메일 본문 작성 또는 Claude에게 초안 시키기
Claude에게 발송 시키기
# 예시 > 명단.xlsx 읽어서 각 사람 이름 넣어 안내 메일 만들고 발송해줘
⚠️ 대량 메일은 반드시 미리보기 확인 후 발송하세요. Claude에게 "먼저 1통만 테스트"를 시키는 게 안전합니다.
SMTP 설정이 필요합니다. 사내 메일 시스템(Dooray IMAP/SMTP) 인증 정보를 .env에 넣어두면 편해요.
